# User-CRUD-API
A RESTful API built with Node.js and MongoDB for managing user data with full CRUD operations.
##  Features
- Create new user
- Read all users
- Get user by ID
- Update user data
- Delete user
- MongoDB database integration
- REST API architecture
- ##  Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- Dotenv
